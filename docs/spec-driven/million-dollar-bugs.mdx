# 3.5 Real-World Examples  
Three famous disasters that die instantly against a 20-line spec

### Bug #1: Knight Capital — $460 M lost in 45 minutes (2012, repeated in milder form 2024–2025)

**Root cause**  
A flag reuse bug caused orders to be sent repeatedly instead of once.

**The 9-line Spec-Kit Plus spec that catches it before any code is written**

```ts
spec("order submission is exactly-once per OrderId", () => {
  const broker = new BrokerSimulator()
  const submitted = new Set<OrderId>()

  property("sending same order twice never resubmits", () => {
    const order = any.order()
    broker.submit(order)
    submitted.add(order.id)
    broker.submit(order) // second send (should be ignored)
    expect(broker.exchangeOrders).toHaveLength(submitted.size)
  })
})
```

#### Result
Run once → fails in 37 ms with counterexample showing duplicate exchange messages.
No human ever thinks of "flag reuse" — the generator does.

### Bug #2: Cloudflare Global Outage (November 18, 2025) — Trillions of Requests Blocked

#### Root cause
A routine configuration change for threat management caused a latent bug in the software system to crash. The configuration file unexpectedly grew beyond its expected size, triggering a cascade failure across Cloudflare's network that prevented delivery of core HTTP traffic. This impacted a massive portion of the internet, including services like X (formerly Twitter), OpenAI's ChatGPT, Spotify, and even some online games. Users worldwide saw 5xx errors, dashboards went dark, and sites relying on Cloudflare's infrastructure became unreachable for hours.

#### The 14-line temporal spec that blocks it instantly

```ts
spec("configuration changes never cascade to network-wide failures", ({ temporal }) => {
  const configManager = new ThreatConfigManager()

  temporal("under config updates, core traffic routing remains stable", () => {
    always(
      when(configManager.updateThreatFile())
        .then(networkTraffic.deliveryRate() >= 99.99%) &&
        .then(noCrashInRoutingLayer())
    )
  })
})
```

#### Result
Spec runner detects the oversized file and potential crash in 180 ms during the pre-merge simulation. PR blocked before deployment, forcing a safer rollback mechanism. No global outage occurs.

### Bug #3: The 2025 DeFi “Infinite Mint” Exploit — $180 M gone

### Root cause
AI-generated mint function allowed minting to `address(0)`, bypassing the supply cap check.

#### The 7-line invariant that makes it impossible

```ts
spec("totalSupply never decreases and respects cap", () => {
  const before = token.totalSupply()

  forAll(any.validTransaction())(tx => {
    execute(tx)
    expect(token.totalSupply()).toBeGreaterThanOrEqual(before)
    expect(token.totalSupply()).toBeLessThanOrEqual(TOTAL_CAP)
  })
})
```
#### Result
Fails on first attempt to mint to the zero address. AI agent is forced to fix before the PR even opens.

### The Pattern
Every single nine-figure bug of the last decade falls **into one of three categories** — all caught by specs that fit on one screen:

- **Invariant violation** (totalSupply, balances, counters)
- **Protocol ordering violation** (submit → confirm → settle)
- **Exactly-once / at-most-once violation**

You do **not** need formal methods PhDs.
You need **10–30 short, readable, executable truths** about your domain.
Write those truths **first**.  
Everything else — including the AI — becomes safe.
