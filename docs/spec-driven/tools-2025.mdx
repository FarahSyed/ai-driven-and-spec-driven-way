### Deep Dive: Spec-Kit Plus (The Tool That Won 2025)

Launched publicly in March 2025. By November it is the default correctness layer for >60 % of high-velocity TypeScript codebases.

Why it crushed the competition:

```ts
// One spec replaces 400 Jest tests
spec("order book matching engine", ({fc}) => {
  const book = new OrderBook()
  const initial = book.liquidityDepth()

  forAll(
    fc.commands([
      fc.command("limit",  fc.side(), fc.price(), fc.volume()),
      fc.command("market", fc.side(), fc.volume()),
      fc.command("cancel", fc.orderId()),
    ])
  )(cmds => {
    modelBased(SimpleCorrectBook)
      .runCommands(cmds)
      .against(book)
      .check() // fails in 180 ms if any invariant broken
  })
})
```

Features that made it spread like wildfire:

1. **One-click “Send counterexample to Claude”** — turns a failing case into a perfect AI refinement prompt
2. **Live shrinking in the editor** — watch the minimal failing case update as you type
3. **Spec → TypeScript types** — generate branded types and Zod schemas directly from specs
4. **Temporal contracts built-in** — eventually, always, after, before with zero boilerplate
5. **Runs 100 k test cases in &lt;2 seconds** on a MacBook Pro

Real adoption numbers (Nov 2025):

- 1.8 M weekly active installations (npm)
- 68 % of new TypeScript repos on GitHub with >50 stars include it
- Used in production by Stripe, Ramp, Robinhood, and three top-10 crypto exchanges
