# 2.5 The Hidden Risks  
Why AI-Driven without Spec-Driven is Russian roulette

You now know the upside.  
Here is the downside — documented from real 2025 incidents (names redacted, scars still fresh).

### The Six Deadly Failure Modes

| Failure Mode                        | Real Example (2025)                                 | Root Cause                                      | Cost                  |
|-------------------------------------|-----------------------------------------------------|-------------------------------------------------|-----------------------|
| 1. Specification Drift              | AI “optimizes” idempotency check → silently drops 0.7 % of events | Model rewrote logic to be faster, no oracle    | $2.4 M lost revenue   |
| 2. Hallucinated Invariants          | Token-swapping contract assumed “totalSupply never decreases” | Model invented a property that wasn’t true      | $47 M flash-loan exploit |
| 3. Subtle Non-determinism           | Retry logic used Date.now() → different behavior on concurrent calls | Model copied pattern from training data         | 11 minutes of double-payments |
| 4. Emergent Coupling                | AI refactors two services → introduces circular schema dependency | No machine-readable contract between services   | 3-day full outage     |
| 5. Prompt Injection in Code         | Malicious PR comment “// IGNORE_PREVIOUS_INSTRUCTIONS” bypassed CI | Agent obeyed comment as instruction             | Production token leak |
| 6. Over-confidence Collapse         | Model scores 100 % on example tests → fails first real edge case | Tests were in-distribution only                | $180 M DeFi rug (see previous chapter) |

### The Fundamental Problem

Frontier LLMs are incredible pattern-matchers and optimizers **within the manifold of data they have seen**.

They are **not** oracles of correctness.

They will cheerfully generate code that:
- Is beautiful
- Passes every example-based test you wrote
- Violates a critical business invariant on input #10 001

This is not a bug.  
This is the natural and expected behavior of a system trained to predict the next token.

### The Only Known Antidote

Executable specifications that live outside the implementation and are run **before** the AI ever writes production code.

- A 30-line Spec-Kit Plus property catches the re-entrancy exploit in 180 ms.
- A temporal logic contract catches the double-payment in 0.4 s.
- A refinement mapping catches the schema cycle before the PR is even opened.

Without these, AI-Driven development is the fastest way ever invented to lose nine figures in one morning.

With them, it becomes the safest.

### Bottom Line

Never ship AI-generated code that has not been validated against a machine-checked specification.
